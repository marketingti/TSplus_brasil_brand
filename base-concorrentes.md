## Remote Access (12 concorrentes)

### CON001 — Citrix (Direto)
- **Site:** citrix.com
- **Foco principal:** Entrega enterprise de aplicativos e desktops virtuais Windows em escala corporativa.
- **O que fazem melhor:** Marca consolidada, confiança enterprise, integração profunda Microsoft/AWS, suporte premium.
- **Ângulo de ataque TSplus:** TSplus oferece 80% de economia com as mesmas funcionalidades, sem a complexidade enterprise.

### CON002 — Microsoft RDS (Direto)
- **Site:** learn.microsoft.com/windows-server/remote/remote-desktop-services
- **Foco principal:** Desktop remoto nativo do Windows Server para publicação de apps e desktops.
- **O que fazem melhor:** Nativo no Windows Server, integração com Active Directory, confiança por padrão.
- **Ângulo de ataque TSplus:** TSplus é mais fácil de configurar, tem portal web sem VPN, impressora universal e menos CALs.

### CON003 — Microsoft Azure Virtual Desktop (Direto)
- **Site:** azure.microsoft.com/products/virtual-desktop
- **Foco principal:** VDI em nuvem Azure com Windows 11 multi-sessão gerenciado na nuvem Microsoft.
- **O que fazem melhor:** Escala cloud, paga por uso, integração nativa Azure AD/M365.
- **Ângulo de ataque TSplus:** TSplus é on-premise ou nuvem própria, custo previsível — licença vitalícia vs. cloud por uso.

### CON004 — Microsoft Windows 365 (Direto)
- **Site:** microsoft.com/windows-365
- **Foco principal:** Cloud PCs dedicados para empresas padronizadas em Microsoft 365.
- **O que fazem melhor:** Dedicado, previsível, integrado ao M365, sem necessidade de VDI complexo.
- **Ângulo de ataque TSplus:** TSplus é on-premise ou cloud própria, licença vitalícia, sem dependência de assinatura Microsoft.

### CON005 — Omnissa Horizon (ex-VMware) (Direto)
- **Site:** omnissa.com/products/horizon
- **Foco principal:** Plataforma enterprise de VDI, spin-off do VMware Horizon sob a marca Omnissa.
- **O que fazem melhor:** História VMware, base instalada grande, enterprise confiável.
- **Ângulo de ataque TSplus:** TSplus é muito mais acessível, sem o overhead enterprise do Horizon.

### CON006 — Parallels RAS (Direto)
- **Site:** parallels.com/products/ras
- **Foco principal:** Entrega de aplicativos Windows e VDI para midmarket e PME.
- **O que fazem melhor:** Interface amigável, bom suporte, multiplataforma, opção cloud ou on-premise.
- **Ângulo de ataque TSplus:** TSplus tem licença vitalícia vs. assinatura Parallels — preço competitivo para PME brasileira.

### CON007 — GraphOn GO-Global (Direto)
- **Site:** graphon.com/go-global
- **Foco principal:** Solução para ISVs transformarem aplicativos Windows em SaaS via acesso remoto.
- **O que fazem melhor:** Foco em ISVs, licença por usuário simultâneo, compatível com Linux server.
- **Ângulo de ataque TSplus:** TSplus é mais conhecido no Brasil, tem melhor portal web, impressora universal e suporte local.

### CON008 — Cybele Thinfinity (Direto)
- **Site:** cybelesoft.com/thinfinity/workspace
- **Foco principal:** Gateway HTML5 para acesso a RDP, SSH, VNC e aplicativos Windows via navegador.
- **O que fazem melhor:** HTML5 browser-based, RDP gateway, compatível com Windows e Linux.
- **Ângulo de ataque TSplus:** TSplus tem melhor ecossistema de suporte no Brasil, portal web mais maduro e licença vitalícia.

### CON009 — Awingu Workspace (Direto)
- **Site:** awingu.com
- **Foco principal:** Workspace unificado HTML5 para acesso seguro a aplicativos e desktops.
- **O que fazem melhor:** Web-based, zero trust, segurança integrada, bom para educação e governo.
- **Ângulo de ataque TSplus:** TSplus tem maior base instalada para Windows legado e melhor suporte no Brasil.

### CON010 — Ericom Connect (Direto)
- **Site:** ericom.com
- **Foco principal:** Acesso remoto seguro, HTML5 e entrega de aplicativos com ZTNA integrado.
- **O que fazem melhor:** ZTNA, HTML5, segurança integrada, enterprise.
- **Ângulo de ataque TSplus:** TSplus é mais acessível e focado em PME/mid-market brasileira.

### CON011 — Apache Guacamole (Indireto)

- **Foco principal:** Gateway web open source para RDP, SSH e VNC sem cliente instalado.
- **O que fazem melhor:** Gratuito, open source, comunidade ativa.

### CON012 — Splashtop (Indireto)
- **Site:** splashtop.com
- **Foco principal:** Acesso remoto e suporte para PME e MSP com foco em simplicidade e preço.
- **O que fazem melhor:** Preço competitivo, fácil de usar, app mobile, bom para PME.
- **Ângulo de ataque TSplus:** TSplus entrega aplicativo via browser (não só desktop), tem load balancing e licença vitalícia.
