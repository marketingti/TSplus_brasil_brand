## Portfólio de Produtos

### 1. TSplus Remote Access

Solução que permite disponibilizar aplicações Windows e sistemas legados via navegador, transformando softwares locais em plataformas acessíveis pela web — sem VPN e sem reescrever o sistema.

**Ideal para:** ERPs legados, sistemas desktop corporativos, ambientes com equipes remotas ou filiais, software houses que desejam oferecer SaaS.

**Recursos principais:**
- Acesso remoto via navegador
- Impressora universal
- Load Balancing e Failover
- Portal web personalizável com identidade da empresa
- Cliente remoto dedicado
- Gateway para múltiplos servidores

**Concorrentes diretos:** Citrix Virtual Apps & Desktops, Parallels RAS, GO-Global, Microsoft RDS, VMware Horizon

**Concorrentes indiretos:** Amazon AppStream, soluções de VDI tradicionais, VPN + RDP convencional

---

### 2. TSplus Remote Support

Ferramenta de suporte remoto completa para equipes de TI, com acesso assistido e não assistido.

**Ideal para:** Help desks, suporte ao cliente, TI interno, operações distribuídas.

**Recursos principais:**
- Controle remoto de dispositivos Windows
- Pastas e grupos de computadores
- Acesso não assistido
- Suporte simultâneo por vários agentes
- Console administrativo

**Concorrentes diretos:** TeamViewer, AnyDesk, LogMeIn Rescue, Zoho Assist, Splashtop SOS, ConnectWise Control

---

### 3. TSplus Advanced Security

Suite poderosa de proteção para servidores Windows, projetada para impedir ataques externos e acessos indevidos. Bloqueia mais de 368 milhões de ameaças por dia.

**Recursos principais:**
- Proteção contra força bruta
- Firewall avançado
- Lista negra inteligente
- Hora permitida para usuários
- Restrição geográfica de acesso (Country Blocking)
- Ransomware Protection
- Tunnel para portas sensíveis

**Concorrentes diretos:** Sophos, Bitdefender, Kaspersky, Duo Security

**Concorrentes indiretos:** Firewalls corporativos, hardening manual do Windows Server

---

### 4. TSplus Server Monitoring

Plataforma para monitoramento completo de servidores, sites e aplicações em tempo real.

**Recursos principais:**
- Dashboard em tempo real
- Alertas automáticos
- Monitoramento de CPU, RAM, rede e disco
- Monitoramento de sites
- Histórico e relatórios
- Agentes remotos

**Concorrentes diretos:** Zabbix, PRTG, SolarWinds, Nagios XI

**Concorrentes indiretos:** Datadog, Prometheus, New Relic

---

### 5. TSplus Two-Factor Authentication (2FA)

Autenticação em dois fatores integrada ao Remote Access. Códigos renovados a cada 30 segundos.

**Recursos principais:**
- Integração nativa com TSplus Remote Access
- Suporte a Google Authenticator, Authy e Microsoft Authenticator
- Camada adicional contra acessos indevidos

**Concorrentes:** Duo, Microsoft Authenticator, Okta Verify, Google Authenticator
